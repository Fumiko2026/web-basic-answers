## Q1. インターネットとは

**問題:** 「インターネット」と「Webブラウザで見るホームページ」は同じものですか？違うとすれば、どう違いますか？

**回答:**

同じではありません。
インターネットは、世界中のコンピュータやネットワークを共通のルールで繋いだ例えれば道路網のような巨大なネットワークのことです。
共通のルールとは、通信の決まりであるプロトコルのことです。代表はTCP/IPで、データの送り先や宛先の決め方を定めています。
ホームページは、その道路を使って運ばれる例えれば荷物のうちの一つです。他の荷物（メールなど）も、同じ道路を通ります。サーバーとブラウザで動きます。
日常生活では、ホームページはブラウザで見ます。メールやオンラインゲームもインターネットを使っていますが、WEBではありません。
